MELINK — МАКЕТ ДЛЯ FIGMA

Це статичний дизайн сайту з першим, фіолетовим логотипом MeLink.
У наборі 24 SVG-макети й відповідні PNG для перегляду.
Дані Марії Савчук та посилання — демонстраційний вміст макета.

ЯК ВІДКРИТИ У FIGMA
Створи порожній Design file і перетягни до нього потрібні SVG-файли.
Файли є векторними. Логотип — у контурах, тексти у вихідних SVG
збережені як текст із шрифтом Arial. Figma може імпортувати їх як
контури; для змінного тексту створи текстові шари за значеннями нижче.
Нативного .fig, Auto Layout та інтерактивних переходів у наборі немає.

РОЗМІЩЕННЯ

На телефоні поля 24 px. Висота основної кнопки: 56 px / 52 px.
Три картки кроків: 384 px, проміжок 32 px.

ПОВЕДІНКА ДЛЯ МАЙБУТНЬОЇ ВЕРСТКИ
«Створити профіль» відкриває майбутню форму створення профілю.
«Як це працює» прокручує до трьох кроків.
«Приклад» відкриває демонстраційну особисту сторінку.
Соціальні кнопки відкривають посилання, які користувач додасть у профіль.
Для hover основної кнопки можна використати #6120D8.
Для клавіатурного фокуса — контур 2 px #7430F5 з відступом 3 px.

ПЕРЕХОДИ ДЛЯ МАЙБУТНЬОЇ ВЕРСТКИ
«Створити профіль» на головній: реєстрація для нового користувача.
Після реєстрації: три кроки створення → публікація → редагування.
«Назад» повертає до попереднього кроку зі збереженням введених даних.
На першому кроці «Назад» веде на головну; чернетка залишається в акаунті.
«Зберегти й вийти»: зберегти чернетку та перейти в кабінет.
Вхід: відкрити редактор або продовжити незавершену чернетку.
«Перегляд» на телефоні: показати попередній перегляд без публікації.
«Профіль / Посилання / Вигляд» у редакторі: ті самі форми, що й у майстрі.
Зберігати редактор лише після натискання «Зберегти зміни».
«Скасувати зміни»: відновити останню збережену версію форми.
«Копіювати»: копіювати реальну повну адресу та показати повідомлення.
Фото: JPG/PNG, ліміт 5 МБ. Опис: до 160 символів.
URL соціального посилання перевіряти перед збереженням.
«Видалити» в картці: прибрати посилання з чернетки; збереження — окремою дією.
Фіолетовий перемикач показує посилання, вимкнений — приховує.
Адреси, контактні дані й результати перевірки — демонстраційний вміст макета.
Це статичні SVG-макети. Сервера, реєстрації та надсилання листів у наборі немає.
